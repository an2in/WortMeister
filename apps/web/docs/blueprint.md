# **App Name**: WortMeister

## Core Features:

- Vocabulary Search & Management: Fast lookup of German vocabulary (A1-B1) with auto-suggest, supporting a static database (CSV/JSON) and allowing users to add and manage personalized word lists. It is backed by a local or cloud storage solution to keep track of words.
- Intelligent Audio Pronunciation: Integration of the Edge TTS API to provide accurate, native-speaker pronunciation for all words in the database and any custom German text entered by the user.
- Spaced Repetition Flashcards: A core learning system based on Spaced Repetition (SRS) to efficiently review and memorize vocabulary, intelligently scheduling words based on user performance to optimize retention.
- Noun Gender & Plural Reflex Game: A mini-game designed to improve rapid recall of German noun genders (der/die/das) and plural forms. The SRS algorithm dynamically increases the frequency of words for which the user makes mistakes.
- Contextual Reading Assistant: A tool that allows users to input custom German text (e.g., articles, study materials). The system automatically analyzes the text, highlights target vocabulary (new or known words), and provides instant lookup and audio pronunciation for words directly within the context.
- Visual Vocabulary Notebook: A personalized learning space where users can add new words. The system automatically performs Part-of-Speech tagging and leverages an AI-powered tool to automatically fetch and display relevant illustrative images, enhancing visual memory and recall.

## Style Guidelines:

- Color scheme: Dark. Chosen for enhanced focus and reduced eye strain during study sessions.
- Primary color: #523399 (a deep royal purple), providing a sophisticated and academic feel for key interactive elements and prominent text.
- Background color: #1C1920 (a very dark purplish-gray), offering a subdued backdrop that promotes concentration.
- Accent color: #5252EB (a vibrant royal blue), used for highlighting important information, calls-to-action, and interactive states to provide strong contrast.
- Headlines font: 'Alegreya' (humanist serif), conveying an elegant and intellectual tone for titles and section headings.
- Body font: 'Inter' (grotesque sans-serif), ensuring readability and a modern, neutral aesthetic for all body text, definitions, and flashcard content.
- Utilize a consistent set of clean, minimalist line icons that clearly communicate functionality without visual clutter. Icons should be easily discernible on a dark background.
- Structured and modular layout focusing on content hierarchy. Prioritize ample whitespace to prevent information overload, ensuring readability and ease of navigation across different learning modes. Adaptive design for optimal display on various screen sizes.
- Implement subtle and purposeful animations for transitions between sections, flashcard flips, and interactive game elements. Animations should enhance user engagement and provide feedback without causing distraction.
